SET EQUALITY: PASS
JOIN PLAN: SCAN o | SEARCH m USING INTEGER PRIMARY KEY (rowid=?) | USE TEMP B-TREE FOR DISTINCT | USE TEMP B-TREE FOR ORDER BY
SUBQUERY PLAN: SEARCH m USING INTEGER PRIMARY KEY (rowid=?) | LIST SUBQUERY 1 | SCAN o
결론: 현재 결과 집합은 같지만 성능은 DB·통계·데이터 분포에 따라 달라져 단정하지 않는다.
